## Overview

**Infiniforge Technologies** is a production-grade enterprise platform blending an e-commerce catalog, LMS with certificates, hosting / domain / SSL management, ticketing, affiliate program, memberships, wallet and CRM — all under one elegant, India-themed brand.

## Highlights

| Module | Capability |
|---|---|
| **Digital Storefront** | Products, categories, coupons, checkout, GST-ready invoices |
| **LMS + Certificates** | Safe video player, quizzes, 95% watch + 85% quiz gated PDF certificates with Ashoka Chakra design |
| **Hosting Suite** | Domains, SSL, servers, deployments, VPS panel and infrastructure reports |
| **Support Desk** | Tickets, workflows, WhatsApp orders, contact submissions |
| **Monetization** | Memberships, subscriptions, wallet, affiliate program with rules and templates |
| **Admin CMS** | Roles, RBAC, backups, audit logs, marketing, PWA control, site content |
| **PWA + Offline** | Installable, push-ready, mobile-first design |

## Tech Stack

- **Frontend:** React 19 · TanStack Start v1 (SSR) · TanStack Router · TanStack Query
- **Styling:** Tailwind CSS v4 · shadcn/ui · Radix UI · Sora + Inter fonts
- **Backend:** Postgres + Row Level Security · Server Functions · Edge APIs
- **Build:** Vite 7 · Bun · TypeScript strict mode
- **Deploy:** Cloudflare Workers (edge runtime)

## Quick Start

```bash
# Install dependencies
bun install

# Start the dev server
bun run dev

# Production build
bun run build
```

Open `http://localhost:8080` in your browser.
